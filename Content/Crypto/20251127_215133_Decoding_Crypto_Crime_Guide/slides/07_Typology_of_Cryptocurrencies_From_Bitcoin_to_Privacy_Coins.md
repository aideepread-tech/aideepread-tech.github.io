# Cryptocurrency Typology

*   **By Convertibility:**
    *   **Convertible:** Can be exchanged for FIAT currency (e.g., Bitcoin). *Where most crime occurs.*
    *   **Non-Convertible:** Value is restricted to a specific environment (e.g., an in-game currency).

*   **By Control:**
    *   **Decentralized:** No central authority (e.g., Bitcoin).
    *   **Centralized:** A single entity controls issuance and rules (e.g., the historic E-Gold).

*   **By Anonymity:**
    *   **Pseudo-anonymous:** Transactions are public, but linked to pseudonymous addresses (e.g., Bitcoin, Ethereum).
    *   **Privacy Coins:** Employ advanced cryptography to hide transaction details and identities (e.g., Monero, Zcash), making tracing more difficult but not impossible.
