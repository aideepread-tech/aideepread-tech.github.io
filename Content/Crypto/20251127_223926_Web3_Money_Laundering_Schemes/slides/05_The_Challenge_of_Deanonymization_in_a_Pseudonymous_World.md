# The Challenge of Deanonymization

- **A Spectrum of Anonymity:**
  - **Pseudonymity:** The default on chains like Bitcoin and Ethereum, where addresses are not directly tied to real-world identities.
  - **Set Anonymity:** Hiding a user's identity within a larger group, making them indistinguishable (e.g., Monero's ring signatures).
  - **Full Anonymity:** Cryptographically hiding both the sender's identity and the transaction path (e.g., Zcash).

- **The Investigator's Playbook:** Deanonymization relies on correlating **on-chain data** (public transaction histories) with **off-chain data** (KYC information from exchanges, communication logs).

- **The Core Challenge:** Sophisticated launderers exploit gaps between these data sources and use privacy-enhancing technologies to erase their tracks, making full reconstruction of fund flows nearly impossible.
