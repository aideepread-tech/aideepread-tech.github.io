# Core Concepts: The Building Blocks of Web3

- **Blockchains:** Decentralized, cryptographically linked ledgers that ensure transactional integrity through consensus protocols like Proof of Work (PoW) or Proof of Stake (PoS).

- **Smart Contracts:** Self-executing programs that automatically enforce predefined rules, forming the foundation of decentralized applications (dApps).

- **A Spectrum of Crypto Assets:**
  - **Coins/Gas Tokens (e.g., BTC, ETH):** Native assets for paying transaction fees.
  - **Utility & Community Tokens (e.g., ERC-20):** Serve functional roles like governance.
  - **Wrapped Tokens (e.g., wBTC):** Enable interoperability across different blockchains.
  - **Stablecoins (e.g., USDC):** Digital assets pegged to a stable reference, like the US dollar.
  - **Non-Fungible Tokens (NFTs):** Unique, indivisible assets representing digital ownership.
