# Toolkit: PETs for Anonymity

### Mixing Services (Tumblers)
- **Function:** The primary tools for transaction anonymity. They pool funds from many users and redistribute them to break the on-chain link between sender and receiver.
- **Underlying Strategies:** Employs commingling, transaction flow obfuscation (TFO), and swapping.
- **Types:** Can be centralized (e.g., Bitcoin Fog) or decentralized, smart contract-based protocols (e.g., Tornado Cash).

### Anonymity-Enhanced Cryptocurrencies (AECs)
- **Function:** Blockchains with privacy features built into their core protocol, offering stronger anonymity than standard pseudonymity.
- **Underlying Strategies:** Achieve Disconnected Fund Flow (DFF) and commingling through advanced cryptography.
- **Examples & Techniques:**
  - **Monero (XMR):** Uses ring signatures and stealth addresses.
  - **Zcash (ZEC):** Uses zero-knowledge proofs (zk-SNARKs).
