# Future Directions

- **Better Data & Models:**
  - Develop semi-supervised and self-supervised machine learning models that reduce the dependency on scarce labeled data.
  - Promote the creation of shared, benchmark datasets for training and testing AML tools.

- **Compliance-by-Design Technology:**
  - **Decentralized Identity (DID):** Frameworks like Polygon ID can support verifiable, privacy-preserving user authorization.
  - **Compliance-Aware PETs:** Develop privacy tools with built-in, selective disclosure mechanisms for regulatory requests.
  - **Compliance Oracles:** Smart contracts that can pull off-chain regulatory data (e.g., sanctions lists) to automatically restrict access.

- **Global Coordination:**
  - Investigate and propose incentive-aligned global AML standards to mitigate regulatory arbitrage.
