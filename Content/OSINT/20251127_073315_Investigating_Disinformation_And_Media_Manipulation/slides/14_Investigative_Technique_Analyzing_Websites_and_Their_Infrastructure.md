# 14. 調查技巧：分析網站及其基礎設施

網站是媒體操弄者獲取收入、收集個資或建立網路灘頭堡的基地。調查網站並將其與更廣泛的網路（社群帳號、空殼公司等）聯繫起來，是揭露資訊操弄的關鍵一步。

## 1. 從「內容」著手

-   **尋找所有權線索**：仔細檢查「關於我們」、頁腳版權聲明、隱私政策或服務條款，尋找任何公司實體或個人姓名。注意不同頁面資訊是否矛盾。
-   **檢查原創性**：複製網站上的「關於我們」或文章段落，貼到 Google 搜尋。如果發現多個網站使用完全相同的文字，這極可能是同一個營運者經營的網站網絡。
-   **反向搜圖**：使用 `Yandex` 反向搜尋網站上的員工頭像。如果發現是圖庫照片，證明該公司是個空殼。
-   **檢查社交連結**：點擊網站上的 Facebook、Twitter 圖示。如果連結無效或導向平台首頁，代表網站是倉促建置的。

## 2. 深入「程式碼」

即使你不懂程式，也能從網頁原始碼中找到寶藏。在 Chrome 中，右鍵點擊頁面，選擇「檢視網頁原始碼」。

-   **尋找追蹤碼**：在原始碼中搜尋 `UA-` (Google Analytics ID) 或 `pub-` (Google AdSense ID)。
-   **串連網絡**：營運者通常會在他們所有的網站上使用同一個追蹤碼。將找到的 ID 貼到 `SpyOnWeb`、`DNSlytics` 或 `AnalyzeID` 等工具中，就可以發現使用相同 ID 的所有其他網站，從而繪製出整個網站網絡的地圖。
-   **檢查存檔**：如果現有網站上找不到追蹤碼，記得去 `Wayback Machine` 檢查該網站的歷史存檔，代碼可能還在那裡。

## 3. 挖掘「註冊資料」

每個網站的註冊資料都儲存在一個中央資料庫中，可以透過「Whois」查詢取得。

-   **使用工具**：`DomainBigData`、`Security Trails` 和 `Whoisology` 是優秀的免費或平價工具。
-   **尋找關聯**：即使註冊資料被隱私保護（顯示為 "Registration Private" 或 "WhoisGuard Protected"），Whois 查詢仍然能提供註冊日期、IP 位址等資訊。更重要的是，它可以告訴你**同一個註冊信箱或 IP 位址還註冊了哪些其他網站**。一個操弄者可能會為某個敏感網站購買隱私保護，卻忘了為其名下的其他網站購買，從而暴露身份。

**核心思路**：透過內容、程式碼和註冊資料中的共同點，將看似獨立的網站串連成一個網絡，是識別背後操弄者的關鍵。
