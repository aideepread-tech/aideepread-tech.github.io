### 🎙️ 第 17 頁：The SAM 3 Agent: Combining with MLLMs for Complex Reasoning

#### 【本頁重點摘要】
*   SAM 3 的能力可被擴展：透過作為一個「視覺工具」，讓多模態大型語言模型 (MLLM) 來指揮，以解決複雜的推理問題。
*   這個組合被稱為「SAM 3 Agent」，其中 MLLM 扮演「大腦」，將複雜的人類查詢分解成 SAM 3 能理解的簡單名詞片語。
*   此 Agent 架構在沒有針對性訓練的情況下，於 `ReasonSeg` 和 `OmniLabel` 等高難度推理分割基準測試中，達到了**零樣本 (zero-shot) 的頂尖水平 (SOTA)**。

#### 【逐字講稿】

(開場白)
到目前為止，我們看到 SAM 3 能精準地處理像「黃色校車」這樣的具體概念。但現實世界的問題遠比這複雜。如果我問：「圖片中，車主最**不可能**從哪個車門上車？」這需要推理，而不僅僅是辨識。這，就是 **SAM 3 Agent** 發揮作用的地方。

我們不把 SAM 3 當作一個孤立的模型，而是將它變成一個強大的**視覺工具**，由一個多模態大型語言模型 (MLLM) 來指揮，形成一個完整的代理系統 (Agentic System)。

##### ① 運作模式：一個扮演「大腦」，一個扮演「眼睛」

這個系統的運作方式，就像一個團隊合作。
*   **MLLM 擔任「大腦」**：它可以是 Gemini、Llama 或 Qwen。當它收到一個複雜的查詢，例如：「找出圖中不靠電力或汽油的交通工具。」
*   **SAM 3 擔任「眼睛」與「手」**：負責執行具體的視覺任務。

整個流程是一個「感知-行動循環 (perception-action loop)」。首先，MLLM 作為「規劃者 (planner)」，會把複雜問題拆解成一連串的簡單指令。例如，它會呼叫一個名為 `segment Phrase` 的工具，然後對 SAM 3 下指令：「分割出『腳踏車』」、「分割出『汽車』」、「分割出『電動滑板車』」。

SAM 3 會回傳它找到的所有物體的遮罩 (masks)。接著，MLLM 會「審視」這些結果，判斷哪些符合「不靠電力或汽油」的邏輯，並迭代這個過程，直到它認為已經完美解答了使用者的問題。

##### ② 處理真正複雜的推理

這個架構的威力在於，它能處理極其細膩和抽象的視覺推理。

> 根據論文中的案例，SAM 3 Agent 能夠回答像「在這張圖片裡，什麼特徵顯示出這隻動物是雄性？」或「如果警察想識別這輛車，圖片的哪個部分會包含有用資訊？」這類需要背景知識和多步推理的問題。

這意味著，我們從「這是什麼？」的層次，躍升到了「這意味著什麼？」的層次。MLLM 的常識推理能力，與 SAM 3 精準的視覺定位能力，兩者結合，釋放出了一加一大於二的強大潛力。

##### ③ 驚人的效能：零樣本下的頂尖水準

最令人驚訝的是，這個 SAM 3 Agent 系統在完全**沒有**針對「推理分割 (Reasoning Segmentation)」或「指代表達式 (Referring Expression)」等任務進行任何訓練的情況下，直接達到了頂尖水平。

*   在 `ReasonSeg` 和 `OmniLabel` 這兩個極具挑戰性的基準測試中，它的 **zero-shot** 表現超越了之前所有經過專門訓練的模型。
*   論文也展示了，這個 Agent 可以搭配不同的 MLLM 大腦，例如 `Gemini 2.5 Pro`、`Llama4 Maverick` 和 `Qwen2.5-VL 72B`，都展現了強大的泛用性。這證明了 SAM 3 作為一個視覺工具的穩健性。
