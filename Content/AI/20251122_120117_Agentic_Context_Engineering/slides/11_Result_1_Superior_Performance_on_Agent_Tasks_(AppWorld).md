# Result 1: Superior Performance on Agent Tasks

On the AppWorld agent benchmark, ACE demonstrated significant improvements over strong baselines.

- **+10.6%** average gain over methods like ICL and GEPA.
- **Outperformed Dynamic Cheatsheet** by an average of 7.6% in online settings.
- **Matched the top-ranked agent** (IBM CUGA, using GPT-4.1) on the public leaderboard, despite ACE using a smaller, open-source model.
- **Surpassed the top agent** on the harder `test-challenge` split.
