# Key Finding: Effective Self-Improvement Without Labels

One of the most significant findings is that ACE can construct effective contexts **without any ground-truth supervision**.

- It leverages natural **execution feedback** and **environment signals**—such as a code script succeeding or failing—to guide the Reflector and Curator.
- On the agent benchmark, ACE still achieved a **+14.8%** average improvement over the baseline without using labels.

This capability is a key ingredient for building truly self-improving and autonomous AI systems.
