# Introducing: Agentic Context Engineering (ACE)

**ACE** is a framework designed to build and manage these comprehensive, evolving playbooks.

It treats context adaptation as a structured engineering discipline for both:
1.  **Offline Optimization** (e.g., creating a powerful system prompt from a dataset).
2.  **Online Adaptation** (e.g., refining an agent's memory during execution).

ACE is built on the principle that contexts should continuously **accumulate, refine, and organize** strategies over time, rather than being compressed or rewritten from scratch.
