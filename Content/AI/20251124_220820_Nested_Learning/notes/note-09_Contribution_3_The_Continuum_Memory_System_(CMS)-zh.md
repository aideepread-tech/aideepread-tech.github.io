### 🎙️ 第 09 頁：Contribution_3_The_Continuum_Memory_System_(CMS)

#### 【本頁重點摘要】
*   **挑戰傳統記憶模型**：現有的 AI 模型通常將記憶分為「短期」（如 Attention）和「長期」（如 MLP），這是一種過於簡化的二元觀點。
*   **提出連續體光譜**：論文引入了「連續記憶系統」(Continuum Memory System, CMS)，主張記憶不是兩個點，而是一個從快到慢、從具體到抽象的連續光譜。
*   **多頻率更新機制**：CMS 由一連串的 MLP 模組構成，每個模組以不同的頻率更新，快的模組捕捉即時資訊，慢的模組則沉澱為長期、抽象的知識。

#### 【逐字講稿】

(開場白)
各位，我們通常習慣把記憶想成兩個獨立的盒子：一個是放著剛發生事情的「短期記憶」，另一個是儲存核心知識的「長期記憶」。就連我們強大的 Transformer 模型，基本上也是這樣設計的：Attention 負責短期工作記憶，而 MLP 層則扮演長期知識庫。但...如果這個非黑即白的二元看法，本身就是一種限制呢？

這就是本篇論文第三個核心貢獻要挑戰的觀點，它提出了一個更符合生物直覺、也更強大的新架構，稱為 **連續記憶系統 (Continuum Memory System, CMS)**。

##### ① 打破二元論：從兩個點到一條光譜
傳統 Transformer 的記憶體系，其實可以看作是 CMS 的一個特例，也就是只有一個快速記憶體（Attention）和一個極慢記憶體（MLP）的 `k=1` 的版本。這就像一個只有兩個檔位的變速箱，要嘛全速衝刺，要嘛幾乎靜止，中間缺乏過渡。

CMS 認為，一個真正能持續學習的系統，其記憶應該像一道**光譜 (Spectrum)**。在這道光譜上，有著不同層次的記憶，它們以不同的速度在演化、在固化。

##### ② 核心架構：多頻率更新的 MLP 鏈
那麼，CMS 是如何實現這個「記憶光譜」的呢？它的設計非常巧妙。

> CMS 不再使用單一的 MLP 層，而是提出了一個由多個 MLP 模組串接而成的**記憶鏈 (a chain of memory modules)**。

各位可以在投影片上看到這個公式：`y_t = MLP^(f_k)(...MLP^(f_1)(x_t)...)`。

這代表什麼意思呢？
*   `MLP^(f_1)` 是一個**高頻率**更新的模組。它可能每處理幾個 token 就會更新一次，負責捕捉最即時、最詳細的上下文資訊。這就像我們大腦裡最表層的、稍縱即逝的記憶。
*   而 `MLP^(f_k)` 則是一個**低頻率**更新的模組。它可能要處理數千、甚至數萬個 token 才會更新一次。它的作用是從海量的資訊中，提煉出最核心、最抽象的知識，並將其沉澱為模型的「世界觀」。

透過這種不同頻率的更新機制，CMS 就在模型內部，創造出了一個從具體到抽象、從短暫到持久的**記憶連續體**。論文中提到，這種設計的目標，就是讓每個頻率的參數 `θ` 都負責壓縮其對應時間尺度下的上下文，最終形成對應層次的抽象知識。
