Nested Learning: The Illusion of Deep Learning Architectures

這篇論文挑戰傳統深度學習架構，提出一種名為「巢狀學習」(Nested Learning) 的新範式。它將模型重新定義為多層次的巢狀優化問題，揭示模型如何透過壓縮自身「脈絡流」進行學習，並為設計能持續學習、自我修改的更強大演算法開闢了新途徑。

By Ali Behrouz, Meisam Razaviyayn, Peiling Zhong, Vahab Mirrokni, Google Research, arXiv preprint

深度學習模型（尤其是大型語言模型）在訓練後本質上是靜態的，無法持續獲取新知識，類似於「順行性遺忘症」。為了解決此限制，本論文引入了「巢狀學習」（Nested Learning, NL），一個受人腦記憶鞏固機制啟發的新學習範式。NL 將模型重新詮釋為一個由多層次、巢狀優化問題組成的整合系統，其中每個層級都有獨立的「脈絡流」與更新頻率。此觀點揭示了現有模型（包含優化器）皆為壓縮其脈絡的聯想記憶體。基於 NL，論文提出了三大核心貢獻：將優化器視為深度記憶體的「深度優化器」、能學習如何自我修改的「自修改泰坦」模型，以及一個「連續體記憶系統」。結合這些概念的 HOPE 架構在持續學習、語言模型和長脈絡推理任務中展現了卓越的潛力，為超越傳統堆疊層級的 AI 自我改進提供了藍圖。

② 新範式：巢狀學習 (Nested Learning)

The Core Challenge: The Static Nature of LLMs

Large Language Models (LLMs) are powerful, yet largely static after deployment. Their knowledge is frozen after the pre-training phase.

The "Anterograde Amnesia" Analogy

LLMs behave like a person with anterograde amnesia:

  1. Intact Old Memories: They retain the vast knowledge from their training data (the "long past").
  2. Inability to Form New Memories: They cannot form new long-term memories from new information encountered in their context window.

The model's parameters (long-term memory) are not updated by new context, limiting them to continuously experiencing the "immediate present" without true learning.

① LLM 的核心困境：知識的「靜態性」

首先，我們必須理解，當前所有的大型語言模型，在完成訓練並部署後，基本上是靜態的。這意味著它們的知識被「凍結」在了預訓練結束的那一刻。

它們可以完美執行在訓練階段學到的任務，但卻無法在不經過昂貴的重新訓練下，從新的對話或資料中學習到新的技能或知識。

它們唯一具備的適應性，來自於所謂的「情境中學習 (in-context learning)」，也就是利用你當前輸入的提示詞來完成任務。但這種記憶是短暫的、臨時的，一旦對話結束，這些資訊也就煙消雲散了。

② 「順行性遺忘症」的精準比喻

為了讓大家更深刻地理解這個困境，論文的作者提出了一個非常精妙的比喻：順行性遺忘症 (Anterograde Amnesia)。

這是一種真實存在的腦損傷，患者會保有發病前的所有記憶，但卻失去了形成新的長期記憶的能力。他們彷彿永遠活在「當下」，每一個新的瞬間對他們來說都是全新的體驗，因為他們無法將新的經歷寫入大腦的硬碟。

這跟 LLM 的處境驚人地相似：

  • 完整的舊記憶：模型擁有在預訓練時學到的海量知識，這就是它的「遙遠過去」。
  • 無法形成新記憶：當我們在對話框中提供新的資訊時，這些資訊只存在於模型的「即時情境 (immediate context)」中，類似於人類的短期記憶。它永遠不會更新模型本身的參數——也就是那些儲存知識的 MLP 層（長期記憶）。

因此，模型被迫在一個沒有學習能力的「永恆當下」中不斷重複運作。

Slide 03

Inspiration: Human Brain's Memory Consolidation

The brain efficiently manages continual learning through neuroplasticity and two key memory consolidation processes:

  1. Online (Synaptic) Consolidation:

    • A rapid process occurring immediately after learning.
    • Stabilizes new, fragile memory traces and begins their transfer from short-term to long-term storage.
    • This is the phase missing in current LLMs.

  2. Offline (Systems) Consolidation:

    • A slower process, often during sleep.
    • Replays, strengthens, and reorganizes memories for permanent storage in the cortex.

Nested Learning aims to create a computational analog to the brain's online consolidation process, allowing models to learn from new experiences.

A New Paradigm: Nested Learning (NL)

Nested Learning represents a model and its training procedure as a set of nested, multi-level, and/or parallel optimization problems.

Key Idea:

Instead of a single, flat architecture with one training loop, NL views a model as an integrated system where different components learn at different speeds and on different types of information.

  • Each component has its own "context flow" and update frequency.
  • This reveals the hidden computational depth and inner gradient flows within existing models (like Transformers).
  • It provides a path to design more expressive learning algorithms with more "levels."

那麼，什麼是巢狀學習呢？

① 重新定義模型架構

簡單來說，巢狀學習的核心思想是：

Nested Learning represents a model and its training procedure as a set of nested, multi-level, and/or parallel optimization problems. (巢狀學習將一個模型及其訓練過程，表述為一組巢狀的、多層次的、且/或平行的優化問題。)

這句話聽起來可能有點抽象。請大家看一下投影片右邊的圖示。傳統的深度學習觀念，就像是這張圖的「扁平化版本 (flattened image)」，我們只看到一個個堆疊起來的黑盒子，卻不了解內部的真實運作。

② 從「扁平」到「整合系統」

NL 則提供了一個立體的、整合系統的視角。它告訴我們，一個模型並非只有一個單一的、緩慢的訓練循環（也就是我們常說的 pre-training）。相反地，模型內部其實充滿了許多個小型的、更快的學習循環。

這個觀點的關鍵在於兩個概念：

  • 脈絡流 (Context Flow)：指的是每個組件所「學習」的資訊類型。對某些組件來說，脈絡是輸入的文字 token；但對另一些組件（例如優化器），它的脈絡可能就是梯度 (gradients) 本身。
  • 更新頻率 (Update Frequency)：指的是每個組件學習和更新其參數的速度。有些組件在每個 token 進來時都會快速更新，而另一些則可能在處理完數千個 token 後才緩慢更新一次。
③ 「白箱化」與「新維度」

當我們用「脈絡流」和「更新頻率」來解構模型時，會帶來兩個巨大的好處：

第一，它揭示了現有模型內部隱藏的計算深度與梯度流。過去我們認為像 Transformer 這樣的模型很神秘，但 NL 讓所有內部的運作過程都變得透明，成為一個數學上的白箱 (mathematically white-box)，我們可以清楚地分析它。

第二，也是更令人興奮的一點是，它為設計學習演算法提供了一個全新的維度 (a new dimension to deep learning)。我們不再只滿足於堆疊更多的「層 (layers)」，而是可以設計擁有更多「級別 (levels)」的演算法，從而實現更高階的脈絡中學習 (in-context learning) 能力。

Deconstruction: Models as Nested Optimization Problems

NL reveals that seemingly simple training processes are already multi-level optimization problems.

Example 1: Training an MLP with Momentum

Contribution 1: Optimizers as Learning Modules

① 解構傳統優化器

  • 第一層 (外層)，是我們熟知的模型權重 W 的更新，它的更新頻率相對較慢。
  • 第二層 (內層)，則是那個動量項 m。論文揭示，這個動量項本身就是一個 「無鍵值的聯想記憶體 (key-less associative memory)」！它的唯一工作，就是學習如何將過去所有的「梯度歷史」壓縮並儲存在自己的參數中。它之所以是 "key-less"，是因為它對待所有梯度都一視同仁，把它們映射到一個單一的目標上。

這篇論文讓我們驚覺，我們習以為常的優化器，內部早已存在著一個記憶與學習的微系統。同樣地，論文也證明了另一個主流優化器 Adam，本質上也可以被看作是一個為模型梯度設計的「最佳聯想記憶體」。

一旦我們接受了「優化器也是學習模組」這個觀點，一個全新的世界就此展開。我們不再需要盲目地發明新的優化器，而是可以像設計神經網路一樣，有系統地去「升級」它內部的記憶元件。

論文提出了三個具體的升級方向：

  • 第一，更具表達力的關聯 (More Expressive Association)：既然動量是個記憶體，那我們可以給它更豐富的資訊。與其讓它是 "key-less" 的，我們可以引入「預處理 (preconditioning)」矩陣 P_i，讓記憶體學會將特定的「梯度 (key)」映射到有意義的「數值 (value)」。例如，這個 P_i 可以包含梯度的二階資訊，如 Hessian 矩陣的資訊，讓記憶更有方向性。

  • 第二，更具表達力的目標 (More Expressive Objectives)：傳統動量的內部學習目標，類似於簡單的點積，這是一種較弱的學習規則。我們可以將它升級為更強大的 L2 回歸損失，這會產生一種基於 「Delta Rule」 的更新方式。這種規則能讓記憶體更有效地管理其有限的容量，從而更好地記住過去的梯度序列。

  • 第三，更具表達力的記憶體 (More Expressive Memory)：這是最直接的想法。既然動量是一個線性的記憶體，那它的表達能力當然有限。我們何不直接用一個更強大的模組來取代它？例如，用一個 MLP 來取代線性的動量矩陣。這就誕生了論文中提到的 「深度動量梯度下降法 (Deep Momentum Gradient Descent, DMGD)」。

Slide 09

Contribution 3: The Continuum Memory System (CMS)

CMS generalizes the traditional binary view of long-term vs. short-term memory.

Instead of one fast working memory (attention) and one slow persistent memory (MLP), CMS proposes a chain of memory modules, each operating at a different frequency.

y_t = MLP^(f_k)(...MLP^(f_1)(x_t)...)

  • Each MLP block MLP^(f_l) is associated with a specific update frequency f_l.
  • Faster-frequency blocks (like f_1) are updated more often, capturing recent context.
  • Slower-frequency blocks (like f_k) are updated infrequently, capturing more abstract, long-term knowledge.

This creates a spectrum of memory persistence and abstraction within the model.

② 核心架構：多頻率更新的 MLP 鏈

透過這種不同頻率的更新機制，CMS 就在模型內部，創造出了一個從具體到抽象、從短暫到持久的記憶連續體。論文中提到，這種設計的目標，就是讓每個頻率的參數 θ 都負責壓縮其對應時間尺度下的上下文，最終形成對應層次的抽象知識。

Introducing HOPE: A Self-Referential Learning Module

HOPE (Hierarchical Online Processing Engine) is the novel architecture proposed in the paper that combines the key contributions.

HOPE = Self-Referential Model + Continuum Memory System

  2. It replaces the standard Feed-Forward Network (FFN) with the Continuum Memory System (CMS), creating multiple levels of persistent memory with different update frequencies.

This results in a learning module that shows promising results in language modeling, continual learning, and long-context reasoning.

② 拋棄傳統 FFN，擁抱連續記憶系統 (CMS)

方程式的第二部分，是 HOPE 的「長期知識庫」。在這裡，我們做了一個非常大膽的改變：我們徹底拋棄了傳統 Transformer 架構中那個巨大、靜態的 Feed-Forward Network (FFN)。

我們都知道，傳統的 FFN 在預訓練結束後就幾乎不再變動，這正是造成模型「順行性遺忘症」的主因。

為了克服這個問題，HOPE 導入了我們前面提到的 Continuum Memory System (CMS)。它不是單一的記憶體，而是一個由多個 MLP 區塊組成的「記憶體鏈」。鏈上的每個 MLP 都有不同的更新頻率：

  • 有些更新得非常快，用來捕捉最近、最即時的資訊。
  • 有些則更新得非常慢，負責沉澱和儲存那些經過時間考驗的、更抽象的長期知識。

透過這種設計，HOPE 就同時擁有了能夠動態適應的「工作記憶」和一個能夠持續演化的「知識光譜」。這讓它成為一個真正意義上的學習模組，並在後續的實驗中，展現了它在語言建模、持續學習、以及長脈絡推理任務上的巨大潛力。

① 一個全新的維度

幾十年來，「深度學習」幾乎等同於垂直地堆疊神經網路層。但巢狀學習 (Nested Learning) 提出了一個根本性的轉變：我們不該只追求深度 (depth)，而應該追求層次 (levels)。

這是在模型設計中開闢了一個全新的維度：優化層級的維度。

想像一下，一個模型不再是一個單一的、笨重的處理流程，而是一個內部擁有多個學習引擎的系統，每個引擎都以不同的更新頻率 (update frequency) 在運作。快的引擎處理即時資訊，慢的引擎則負責沉澱、提煉出更抽象的知識。這才是更接近生物智慧的模式。

② 從黑箱到白箱的理解

巢狀學習最令人興奮的一點是，它不只是一個新的模型架構，它更像是一副新的眼鏡，讓我們能以前所未有的清晰度，看透現有模型的內部運作。

過去我們視為理所當然的工具，例如 Adam 優化器，或是 Attention 機制，在 NL 的框架下被重新詮釋。它們不再是神秘的黑箱，而是可以被數學方法解構的、各自擁有目標函數的「學習模組」。當我們能看懂它們，我們就能夠系統性地去改進它們，就像我們在前面看到的，可以設計出更有表達力的優化器。

③ 實現真正的「持續學習」

讓我們回到一開始提到的「順行性遺忘症」比喻。目前的 LLM 就像無法形成新記憶的病人，知識被凍結在預訓練完成的那一刻。

巢狀學習透過模仿大腦的「線上記憶鞏固」過程，為這個根本性難題提供了一條有原則的解決路徑。這不是紙上談兵，而是讓我們能打造出真正能夠從新經驗中學習、持續自我演進的 AI 模型。這代表著，未來的 AI 不僅僅是擁有記憶，更能創造新的記憶。
