# Fundamental Unit: Learning as Associative Memory

NL redefines the concepts of memory and learning from a neuropsychology perspective:

*   **Memory:** A neural update caused by an input.
*   **Learning:** The process for acquiring *effective and useful* memory.

---

### Associative Memory

The core building block is the **associative memory**: an operator `M` that learns to map a set of keys (K) to a set of values (V) by minimizing a quality-of-mapping objective.

`M* = argmin_M L(M(K); V)`

In NL, **all elements** of a computational model—from attention mechanisms to the optimizer itself—are treated as associative memory systems that learn by compressing their own specific context flow.
